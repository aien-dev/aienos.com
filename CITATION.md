# Citing the papers and development method

## Published preprints

M. Drake Stapleton (2026). *Computing Machinery and Understanding: From the Imitation Game to the Turing*. Zenodo, deposited record v1, published 2026-10-17. <https://doi.org/10.5281/zenodo.23437498>.

M. Drake Stapleton (2026). *Computing Machinery and Understanding: The Turing as a Measure Emerging from AIEN*. Zenodo, deposited record v1, published 2026-10-17. <https://doi.org/10.5281/zenodo.23437568>.

These are preprints, not peer-reviewed publications. A Zenodo record's version and publication date are distinct from the manuscript's printed version and date. Cite the deposited edition when using its DOI; a current website PDF or LaTeX file is not necessarily byte-identical to that edition.

The [manuscripts and website source](public/research/) live in this repository. The [Omega implementation and evidence](https://github.com/aien-dev/omega-mv) live in a separate repository. Identify the exact commit or release used when citing executable behavior. These paper DOIs do not identify a software release of either repository.

## Human-Directed Agentic Engineering

For the development method and a systems-software case study:

Gregory M. Kurtzer (2026). *Ginux: Building an Independent Kernel That Runs Linux Userspace through Human-Directed Agentic Engineering*. Technical report, v1, Zenodo, published 2026-10-27. <https://doi.org/10.5281/zenodo.23682548>.

This attribution credits Kurtzer's documented HDAE method and Ginux case study. It does not attribute AienOS code or Stapleton's papers to Kurtzer, imply endorsement, or claim that the report originated the general idea or phrase.

For publication preparation, see Zenodo's guides to [creating a paper upload](https://help.zenodo.org/docs/deposit/create-new-upload/) and [GitHub software archiving](https://help.zenodo.org/docs/github/). A paper DOI, a software-version DOI and a concept DOI identify different resources.
