**2/10**
A clean run from an empty folder: Qwen3.8-27B, official weights converted to 4 bits (13.65 GB), 14.15 tokens per second, wall clock. That is 193 GB/s of weights read, 70.8% of the Spark's 273 GB/s memory limit.

**3/10**
The ceiling is the memory, so we measured the memory first. Every path loaded at once (GPU, CPU, disk) moved 222.3 GB/s, 81.4% of 273. 273 is the wall; 222.3 is the most any mix of paths has moved.
https://github.com/aien-dev/omega-mv/blob/3c8ce239/docs/MACHINE_CEILING.md

**4/10**
How do you talk to a GPU without CUDA? One C file, 813 lines. It opens the open NVIDIA kernel driver and uses 8 of its commands, plus 11 of its shared-memory module. Omega writes the GPU's machine code itself.
https://github.com/aien-dev/physics-mv/blob/6d7cf0d4/nvrm/nvrm.c

**5/10**
