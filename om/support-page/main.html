Support via X Money

X Money is currently US-only. The button opens my X profile, not a payment checkout.

How to send support

  1. Open X and select Money.
  2. Choose Send Money.
  3. Search for @mdrakestapleton, check the recipient, then choose the amount to send.
Who can send through X Money

Sending money requires an X account with access to X Money. Sending through X Money is peer-to-peer between X users, and X offers no public payment link I can put here.

Read the X Money FAQ and eligibility requirements

Other ways to help

If giving isn't an option, that's completely fine. Reading, trying the software, sharing a useful page or contributing a fix helps too. Nothing here is gated on a donation.
