Writing Omega programs

1. Compile and run

git clone https://github.com/aien-dev/omega-mv && cd omega-mv
git checkout e5b32567a7aff3ce594e3254a622a846a6cd190b
sha256sum seed/out/omc      # must print the pinned hash
sh seed/omega-from-seed.sh  # optional: rebuild omc from the 408-byte loader
seed/out/omc < prog.om > prog; echo "compile $?"
chmod +x prog && ./prog; echo "exit $?"
  • omc reads the unit on stdin and writes the executable on stdout. Exit 0 means accepted. Any other exit is the error number, and stderr has one line omc: line N: error K.
  • Never run the output of a refused compile: stdout may still hold bytes.
  • A unit with fn main is program mode (an executable). A unit without it is function mode (raw machine words for a host to call); never execute function-mode output directly.
  • Check behavior, not compile success: compare stdout bytes and the exit status with what you expected, and run one deliberately wrong variant to see the check fail.
  • To check a whole set the way this repository does: examples/gate.sh path/to/seed/out/omc prints PASS name or FAIL name: reason per program and ends GATE PASS examples=N ... or GATE FAIL ... (exit 1); a different compiler hash exits 2.

2. Program shape

note hello: the smallest complete program
text msg "hello, world\n"
fn main to int
k = write 1 msg 0 len msg
if ne k long len msg
ret 1
end
ret 0
end

(examples/hello.om). The rules it shows:

  • One statement per line. No semicolons, no braces. Blocks (fn, if, else, while, for, struct) close with end. Indentation is optional.
  • Prefix words only. Every operation is a word followed by its values: add x 1, mul add a b c, lt i n. Each word has a fixed number of values. Parentheses may group a value and add nothing: (add a b).
  • Comments are note lines. // and # are refused (error 16).
  • fn NAME p1 T1 p2 T2 ... to R, result R a type or void. Parameters fill 6 slots: an OM-2 unsized view T * / edit T * takes 2 (pointer and count), every other parameter 1 (a scalar, a sized array, a struct). Two unsized views plus three scalars is error 9 (examples/om2_param_slots.om, mistake_om2_param_slots.om). fn main to int takes no parameters and its ret value is the exit status (0..255).
  • Assignment is name = value. The first assignment creates the name with the value's type. The = is optional, which is a trap: return x is accepted as "assign x to a new name return".
  • A function may call a function defined later in the unit, and program-mode functions may recurse.
  • Top-level lines are note, fn, text, global, const, struct, and in OM-2 units layout, abstract, holds and export fn. struct and layout lines come before the first fn (error 9 after it). A const is visible only after its line.

3. Types and values

  • No implicit conversion. Both values of an operation have one type (error 7). Convert with the type word: long x, uint b, f64 n.
  • A bare number takes its type from context: the other value of its operation, the parameter it is passed to, the result type at ret. With no context it is error 11: write x = uint 5, never x = 5 for a new name.
  • Integer literals are decimal with an optional leading -. A literal that does not fit its type is error 8. No character literals: write uchar 65, not 'A' (error 3).
  • Float literals need digits on both sides of the dot: 2.0f64, 1.0e30f64, 0.5f32. The suffix is optional where context gives the type.
  • Hex only in OM-2 (section 9): lowercase 0x and lowercase digits, value must fit (int 0xffffffff is error 8; write int -1).
  • sizeof T, sizeof S and offsetof S f are compile-time ulong constants.

  • and, or, xor on integers of any width are bitwise, not logical: and ulong 12 ulong 10 is 8 (examples/int_bits_and.om). Compare first when you want a bool.
  • and / or on bools evaluate both sides; there is no short circuit (examples/mistake_short_circuit.om traps 3 on the index the C reader would expect to be skipped). Test the index in an outer if.
  • Comparisons follow the type: on ulong, lt x y with x = 2^64-1 and y = 1 is false.
  • div and rem on signed values round toward zero; rem takes the dividend's sign; shr on a signed value keeps the sign.
  • A function with a result is a value, not a statement: write v = f 1, never a bare f 1 (error 7). A void function is called as a statement.
  • A call is the name then its values with no brackets or commas: ret f 1 2.

  • Integer conversions are checked: uchar x with x = 300 traps 5. Keep the low bits on purpose with a mask: uchar and x 255.
  • Float to integer truncates toward zero and saturates at the type's limits; NaN gives 0; it never traps (examples/float_to_int.om). No float operation traps: 1/0 is infinity, 0/0 is NaN, and NaN compares false except with ne.

6. Loops and bounds

  • while COND bound N runs the body at most N times, N 1..999999 (error 8 outside). Without bound the limit is 1000000. One more pass traps 4. Choose N from an argument you can write down in a note, for example "every pass consumes at least one byte of a 65536-byte input".
  • for i T K runs i from 0 to K-1. for takes no bound (error 5); K is the limit.
  • break and continue work in both loops. There is no else if: nest an if inside else.
  • No loop runs forever and recursion is bounded by the stack.

7. Arrays, texts, globals, structs

  • Local array: a = new T N v, N elements each v, only in a function's outermost block (error 9 inside a block). N is a literal or an integer const; a variable N is error 16. There is no heap and no free (error 9).
  • Global array: global NAME T N at top level, zero-filled, program mode only. A global is never an argument (error 19); a function uses it by naming it.
  • Text: text NAME "bytes" is a read-only uchar array. Escapes are only \n \t \\ \" (error 22 for others).
  • Array parameters state type and exact length: a view uchar 64 (read-only) or a edit uchar 64 (writable). Another length is error 7. In OM-2, a view T * / a edit T * take any length. Writing to a view or text is error 20.
  • get A i / put A i v: a literal index outside the array is error 21; every other index is checked at run time (trap 3). There are no pointers and no address arithmetic.
  • Structs: struct Pair a uint b long end, before the first fn. Every field is an 8-byte cell, so a struct is never a wire or file layout. p = new Pair 5 -12, pass as p edit Pair or p view Pair (examples/structs.om).
  • Bytes on the wire: build them with shifts and masks into a uchar array (examples/wire_le.om); OM-2 also has layout.

8. Names and limits

  • Variable, parameter, global, text, const, struct and field names: at most 8 characters (error 13). Function names: at most 63, but see section 13 for names that start with an 8-letter keyword.
  • A new name may not repeat a visible name, a function or a struct (error 10). A name first assigned inside a block ends at that block's end; assign it before the block to keep it.
  • Reserved words cannot be names, including `len read write text new free view edit global note exit const bound and every host word (stat, link, send, random, fork, ...). len` as a name is error 16, free is error 9.
  • 16 registers per function hold parameters, live names, loop counters and the temporaries of the current statement. The 17th is error 12 (examples/err12_registers.om). The fix is structural: move part of the work into a helper function that takes a few scalars and returns one value, end the life of names you no longer need by computing them inside a block, and split a long nested expression into several assignments of one or two words each.
  • Size limits: an array up to 16777216 elements, 4 MiB of local arrays per function, 1 GiB of globals (error 23).

9. OM-2 units

A unit whose first line that is not blank or note is exactly om2 is an OM-2 unit. OM-1 code keeps its meaning inside it. OM-2 adds:

  • lowercase hex literals; rotr x n, rotl x n on unsigned types (trap 7 for an amount outside 0..width-1);
  • unsized parameters a view T * / a edit T * with len a the run-time count;
  • part A off n, only as an argument to an unsized parameter: the n elements of A from off, checked at run time (trap 3). A part of a global is error 19; as a value of its own it is error 9; to a sized parameter it is error 7;
  • for i T K unroll, fn ... inline, layout (external byte layouts), fresh scratch arrays (error 27), abstract types with seal / open (error 28), export fn (at most 32, error 14);
  • executable contracts: requires and ensures lines at the start of a function, invariant as the first line of a loop body. A failing requires traps 9 (exit 109), a failing ensures or invariant traps 10 (exit 110). A clause may not call a function, use floats or host words (error 30). The first line om2 release erases the checks (examples/contract_release.om).

Examples: om2_tour.om, om2_views.om, om2_hex_rotr.om, contracts_ok.om.

10. Host I/O

  • Every host word returns a long: a count, or minus the Linux errno. read may return fewer bytes than asked, 0 at end of input, or a negative error; write may write fewer. Loop until done and handle k < 0 and k == 0 separately (examples/stdin_count.om).
  • Descriptors, flags and modes are int; offsets, counts and capacities ulong; buffers uchar arrays. Slices are checked before the kernel call (trap 3).
  • main takes no parameters: read arguments with argcnt and argread (examples/echo_args.om) and the environment with envcnt and envread (examples/env_read.om). Short capacity returns -105.
  • Host words carry the process's own permissions; they are not a sandbox.

13. Known compiler defects at the pin

  • bitcast across signedness below 64 bits (fix proposed in draft omega-mv #896, not in the pin): the result does not compare equal to the reinterpreted value. Observed wrong: uint to int (4294967295 is not -1, and adding 2 traps 1), int to uint, ushort to and from short, uchar to and from byte, and f32 to int (-1.0 is not -1082130432 and not below 0). Observed correct: ulong to and from long, f64 to long, f32 to uint, int to f32. Until a fixed compiler is pinned, do not bitcast between narrow integer types or from f32 to int; decode signed 8, 16 and 32-bit values arithmetically: load into long, then subtract 2^32 (or 2^16, 2^8) when the value is at least 2^31 (2^15, 2^7), as examples/wire_le.om does. For float bits, bitcast uint of an f32 is correct.
  • Empty text through view uchar * (omega-mv issue #775): the parameter does not arrive with len 0 (observed 60 and 28, depending on the other texts in the unit), so a loop over it runs past the text (a crash has been reported; not reproduced here). Workaround: pass part e 0 0, which arrives with len 0 (examples/empty_text_part.om).
  • Function names that begin with an 8-letter keyword: a function name longer than 8 bytes whose first 8 bytes are a keyword (continue_x, truncate_number, sockname_x, execprog_x, peercred_x) is error 16, although function names may be 63 characters. Shorter keyword prefixes are fine (breakx, whilex, getpid_x). Workaround: rename (cont_x, trunc_num) (examples/defect_keyword_prefix.om).
  • A fix for both is in progress in omega-mv; until a new compiler is pinned, use the workarounds.
  • OMEGESE 9.9 lists + - * / for floats; the compiler refuses them. Write add sub mul div.

Checking the examples

Write every file on this page into one directory tree with the paths in the labels, then run bash examples/gate.sh /path/to/omc. The gate refuses any compiler but the pinned one. It compiles each program, runs it with an empty environment plus its .env in an empty scratch directory under a 20 second timeout, compares the exit status and the stdout bytes, requires an empty stderr, prints one PASS or FAIL line per program and ends with GATE PASS examples=N when all of them match. The aienos.com build checks that the files in llms-full.txt are these files, and om/omega-reference/llms-check.sh extracts them from llms-full.txt and runs this gate on them.

File: examples/gate.sh

#!/usr/bin/env bash
# gate.sh OMC: compile and run every worked example against its expected result.
#
# Covers examples/*.om and skills/*/examples/*.om. Each NAME.om needs NAME.expect:
#   compile N         required; the compiler's exit status
#   stderr LINE       required when N is not 0; the compiler's whole stderr is exactly LINE
#   exit N            required when N is 0; the program's exit status
#   input dir         optional; the compiler reads a directory instead of NAME.om (error 1)
#   output full       optional; the compiler writes to /dev/full (error 2)
# Optional fixtures: NAME.stdout (exact stdout bytes, absent means empty), NAME.stdin (piped in,
# so reads can be partial), NAME.args (one argument per line), NAME.env (one KEY=VALUE per line).
# Every program runs with `env -i` plus NAME.env, in an empty scratch directory, under a 20 s
# timeout, and must write nothing to stderr. A compile that is not expected to succeed is never run.
#
# The compiler must match the pinned sha256 below; a different binary is refused, not tolerated.
# Exit 0 only when every example passes; 1 on any failure; 2 on a usage or pin error.
set -u

PIN_REV=e5b32567a7aff3ce594e3254a622a846a6cd190b
PIN_SHA=2c82480596bbdc50cda9626866209ef662d5834f278f839ff4ce0250c495029f

if [ "$#" -ne 1 ]; then
    echo "usage: $0 /path/to/omc   (omega-mv $PIN_REV seed/out/omc)" >&2
    exit 2
fi
omc=$(cd "$(dirname "$1")" && pwd)/$(basename "$1")
if [ ! -x "$omc" ]; then
    echo "GATE FAIL $1 is not an executable file" >&2
    exit 2
fi
got=$(sha256sum "$omc" | cut -d' ' -f1)
if [ "$got" != "$PIN_SHA" ]; then
    echo "GATE FAIL omc sha256 $got, pinned $PIN_SHA (omega-mv $PIN_REV)" >&2
    exit 2
fi

here=$(cd "$(dirname "$0")" && pwd)
root=$(dirname "$here")
work=$(mktemp -d)
trap 'rm -rf "$work"' EXIT

pass=0
fail=0
total=0

bad() {
    echo "FAIL $name: $*"
    fail=$((fail + 1))
}

# Expected files without a program are a silent loss of coverage, so they fail too.
for f in "$root"/examples/*.expect "$root"/skills/*/examples/*.expect; do
    [ -e "$f" ] || continue
    if [ ! -e "${f%.expect}.om" ]; then
        name=$(basename "${f%.expect}")
        total=$((total + 1))
        bad "expect file without $name.om"
    fi
done

for src in "$root"/examples/*.om "$root"/skills/*/examples/*.om; do
    [ -e "$src" ] || continue
    base=${src%.om}
    name=${base#"$root"/}
    total=$((total + 1))
    if [ ! -f "$base.expect" ]; then
        bad "no $name.expect"
        continue
    fi
    want_compile= want_stderr= want_exit= input=file output=file
    while IFS= read -r line || [ -n "$line" ]; do
        case $line in
            "compile "*) want_compile=${line#compile } ;;
            "stderr "*) want_stderr=${line#stderr } ;;
            "exit "*) want_exit=${line#exit } ;;
            "input dir") input=dir ;;
            "output full") output=full ;;
            "") ;;
            *) want_compile=invalid ;;
        esac
    done < "$base.expect"
    case $want_compile in
        ''|invalid|*[!0-9]*) bad "malformed $name.expect"; continue ;;
    esac
    if [ "$want_compile" != 0 ] && [ -z "$want_stderr" ]; then
        bad "$name.expect has no stderr line"; continue
    fi
    if [ "$want_compile" = 0 ]; then
        case $want_exit in
            ''|*[!0-9]*) bad "$name.expect has no exit line"; continue ;;
        esac
    fi

    d=$work/$(echo "$name" | tr / _)
    mkdir -p "$d/run"
    in=$src
    [ "$input" = dir ] && in=$d/run
    out=$d/p
    [ "$output" = full ] && out=/dev/full
    "$omc" < "$in" > "$out" 2> "$d/cerr"
    rc=$?
    if [ "$rc" != "$want_compile" ]; then
        bad "compile exit $rc, expected $want_compile: $(cat "$d/cerr")"
        continue
    fi
    if [ "$want_compile" != 0 ]; then
        if printf '%s\n' "$want_stderr" | cmp -s - "$d/cerr"; then
            echo "PASS $name (compile $rc: $want_stderr)"
            pass=$((pass + 1))
        else
            bad "compiler stderr '$(cat "$d/cerr")', expected '$want_stderr'"
        fi
        continue
    fi
    if [ -s "$d/cerr" ]; then
        bad "compiler stderr not empty: $(cat "$d/cerr")"
        continue
    fi

    chmod +x "$d/p"
    args=()
    envs=()
    if [ -f "$base.args" ]; then mapfile -t args < "$base.args"; fi
    if [ -f "$base.env" ]; then mapfile -t envs < "$base.env"; fi
    if [ -f "$base.stdin" ]; then
        (cd "$d/run" && cat "$base.stdin" | timeout 20 env -i "${envs[@]}" "$d/p" "${args[@]}" > "$d/out" 2> "$d/rerr")
    else
        (cd "$d/run" && timeout 20 env -i "${envs[@]}" "$d/p" "${args[@]}" < /dev/null > "$d/out" 2> "$d/rerr")
    fi
    rc=$?
    want_out=/dev/null
    [ -f "$base.stdout" ] && want_out=$base.stdout
    if [ "$rc" != "$want_exit" ]; then
        bad "exit $rc, expected $want_exit"
    elif ! cmp -s "$want_out" "$d/out"; then
        bad "stdout differs from $(basename "$want_out"): $(od -An -c "$d/out" | tr -s ' ' | tr -d '\n' | cut -c1-200)"
    elif [ -s "$d/rerr" ]; then
        bad "program stderr not empty: $(cat "$d/rerr")"
    else
        echo "PASS $name (exit $rc, $(wc -c < "$d/out" | tr -d ' ') stdout bytes)"
        pass=$((pass + 1))
    fi
done

if [ "$total" = 0 ]; then
    echo "GATE FAIL no examples found under $root"
    exit 1
fi
if [ "$fail" = 0 ] && [ "$pass" = "$total" ]; then
    echo "GATE PASS examples=$total pass=$pass fail=0 omc=$PIN_SHA"
    exit 0
fi
echo "GATE FAIL examples=$total pass=$pass fail=$fail omc=$got"
exit 1
