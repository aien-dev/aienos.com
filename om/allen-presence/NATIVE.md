# Allen's native presence

The visual reference is the native galaxy build in [aienux at da55660ea7337f2b6a42095fcd1fb6ddebe1cc7c](https://github.com/aien-dev/aienux/tree/da55660ea7337f2b6a42095fcd1fb6ddebe1cc7c/native/kernel/ui). Drake identifies this galaxy experience as the Allen he uses on his iMac. The available old machine report names an earlier build; it is not evidence that the newer galaxy never ran. The reference selection follows his current observation, not that stale report. No physical iMac was accessed or changed for this work.

## What the native source does

- `night.c` draws the photographic Milky Way layer, catalogue stars and galaxies, then the two lensing black holes. The native opening merges the holes at 12000 ms. Allen begins to gather at 12300 ms and completes formation at 15300 ms.
- `mind.c` draws a Fibonacci-lattice cloud, its nearest-neighbour threads, pale blue-white points, a blue/violet halo and a warm heart. Idle rotation uses `spin = 349`; the source describes a turn in 48 seconds. The breathing phase uses 5500 ms. Listening, thinking and speaking change the same stateful renderer, not a replacement icon.
- `allen_ui.c` places the heart at half the width and 40 percent of the height. Its reference layout is 1920 by 1080, with a 720 by 54 input bar at `height - 150`, all scaled by its native scale factor.
- While typing, key events light pulses upward through the mind and feed the ink field. On submission the typed line rises and fades over 900 ms. Nine thoughts leave on curved paths, starting at `150 + i * 40` ms, with duration `850 + hash(i, 1, 5) % 300` ms. Literal individual glyphs flying on each keystroke are a requested web enhancement, not a claim about the old native input renderer.
- Native replies appear below Allen, not as a transcript wall. Letters start 35 ms apart, fade in over 260 ms and rise by six reference pixels over 360 ms. They change from RGB(255,212,150) to RGB(234,238,252) over 900 ms. Each word pulses his heart. The native view holds only the current reply; the web adds an explicit session-history panel.
- The spinning tube is the native dusk/sleep transition, lasting 4200 ms. **The web opening on Allen's own screen reuses the iMac dusk scene.** The home door uses the native two-hole opening. Reordering dusk as an entrance is an intentional presentation choice, not the native boot order.

These are source constants and source descriptions, not newly measured frame-rate claims.

## Sound

`chirp.c` is the only native sound generator. It produces the merger chirp from night time 11360 through 12300 ms, with the merger at 12000 ms. The generated browser WAV is synthesized by `om/allen-audio/chirp.om`, not a recorded imitation. The source contains no separate tube, birth, boom or voice-like sound. The browser therefore does not invent one. WebAudio starts only from a visitor's gesture; mute is a separate local preference. See `om/allen-audio/check.sh` for the independent original-C oracle and negative control.

## Browser boundaries

The page skeleton, transport client and presence controller are generated by seeded Omega. The native pixel renderer is temporarily compiled from the pinned original C to WebAssembly so its integer arithmetic and pixels can be compared directly. The page labels that boundary honestly; it does not claim that the C pixels were drawn by Omega. `DEPENDENCIES.md` records the native renderer and the required Omega successor.

The accessible DOM remains responsible for the input, last reply, history, consent, controls and glass panes. The transport retains its existing same-origin routes. An anonymous session sends no visitor key. Remember-me and the X pixel remain separate explicit choices. Drake's speaker label is accepted only from the authenticated session channel's human event. Model text cannot choose it.

Reduced motion leaves a static glow and reveals text without animated travel. Hidden documents stop drawing. The corner launcher and the full-screen canvas share the same renderer. The optional history belongs to the current tab; saving a project is a separate action.

## Reproduction

Regenerate the presence artifacts with `OMEGA_ACCEPT_CHANGE=1 sh om/allen-presence/check.sh`, and the page with `OMEGA_ACCEPT_CHANGE=1 sh om/allen-page/check.sh`. Run the same commands without acceptance to detect drift. Native renderer and audio regeneration have their own pinned recipes under `om/allen-scene` and `om/allen-audio`. Generated artifacts and their hash sidecars must be committed with their Omega sources.

Pixel comparisons must name the native source pin, viewport, frame time and complete state sequence. Comparing different times or a QEMU screen that contains firmware UI is not a renderer parity verdict. Native-host parity and emulator-frame parity are separate observations. Production checks use canvas `getImageData` through `tab.evaluate`, not a screenshot command that hangs in this environment. No emulator or browser result qualifies physical iMac hardware.
