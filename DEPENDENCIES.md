# Site dependency boundaries

The whole-site Omega cutover is pending in draft PR #122. This ledger distinguishes page generation, data collection, browser execution and independent verification. It does not claim that pending code is deployed or qualified.

`om/site/build.om` owns source composition and compiler process handling. The initial command invokes the pinned compiler on that conductor; shell redirection and `chmod` at this bootstrap boundary are operating-system launch operations, not page generation logic. The HTML, CSS, JavaScript, JSON surfaces, feeds and mirrors are authored or generated by the Omega units. Original papers, images and authored static prose remain data inputs, not executable host renderers.

## Retained collection and publication tools

The Rust `site-builder` command remains the production builder until cutover. After cutover, its `verify`, `ledger-project`, `ledger-check`, `facts`, `agents` and `progress` duties remain separately identified rather than described as Omega. Its current manifest is `crates/site-builder/Cargo.toml`; resolved dependency versions must be recorded from the actual verification build before publication of a completed cutover receipt.

- Rust and Cargo on the integration host: `rustc 1.98.1 (48a229cea 2026-09-01)`, `cargo 1.98.1 (797e8a9bc 2026-08-05)`.
- Facts, repository catalog and project-history collectors use the public GitHub API. Their Omega successor is a native collector using the HTTP/JSON work coordinated in omega-mv; this migration does not silently replace or disable the existing refresh path.
- The installed ledger publisher's Rust projection is an existing fail-closed privacy boundary. The site's Omega `ledger.om` checks and renders published input; replacing the installed publisher is a separate authorized operational change. Do not bypass the projection before staging the `data/now` branch.
- `crates/hive-feed` and the edge receiver remain the existing live-feed pipeline. `om/hive-render/render.om` already owns board markup. This site rewrite neither restarts the services nor changes their publication authority.

## Browser dependencies

- Native browser HTML/CSS/JavaScript APIs execute the output. Browser JavaScript is emitted from `.om` source units, as for the established Hive #105 path; it is not claimed to execute as native Omega in the browser.
- D3 `7.9.0`, vendored at `public/vendor/d3-7.9.0.min.js` with its license, remains the existing project-progress visualization dependency. Its successor is a first-party Omega-authored browser visualization; it is not part of the native generator or needed to read the progress source data.
- Allen's scene, audio and panes are integrated from their separately pinned modules. Any authorized native-scene-to-WASM dependency must retain its own source/compiler provenance and disclosure; do not relabel that boundary as an Omega renderer.
- The sole optional third-party tracker is the X loader configured for pixel `rfrlz`. It is never a page build dependency and never loads before explicit separate consent. No new trackers, remote fonts or unconditional external scripts are introduced.

A missing check is `NOT_RUN`, not a pass. The recorded versions above came from version commands, not from a build, test, browser or deployment run.
