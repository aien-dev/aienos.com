Written for an outside, independent security audit. Revision described:
`deebe99863a4a97d45d711649b06ae95da14d821` on `main`, 2026-10-26. Everything below is taken from
the repository's own files at that revision; items marked NOT_RUN were not executed while writing

## What this repository is

The source of the AienOS website, www.aienos.com. A Rust program (`crates/site-builder`, Maud
templates) renders the pages, copies hand-written files from `public/`, rewrites every head and
writes Markdown mirrors and machine-readable files. GitHub Pages serves the output as origin; an
nginx edge adds Markdown negotiation and the opt-in live Hive feed. Some pages (`/hive/`,
`/alpha/`, `/support/`) are generated by seeded Omega programs under `om/`, compiled by a committed
`omc` binary. `crates/hive-feed` is opt-in telemetry tooling that does not run during static
builds. `public/install.sh` is published at `https://aienos.com/install.sh`. The site is live and
rebuilt hourly.

## What to review, in priority order

1. `.github/workflows/pages.yml`. Triggers: hourly schedule, manual dispatch, push to `main` and
   `data/now`. Build job has `contents: read` and uses `github.token` to collect public facts;
   only the deploy job holds `pages: write` and `id-token: write`. A push to `data/now` also
   deploys. The build lays in `now.tsv` from the `data/now` branch and runs `ledger-check` before
   building. Actions pinned by sha.
2. Privacy projection: `site-builder ledger-project` and `ledger-check` (the public `/now/`
   ledger), `/dash/` inputs (`public/data/accounts.tsv`, `routing.tsv`), and
   `crates/hive-feed/src/privacy.rs` (whitelist and credential screening of Hive text).
3. Output escaping: `om/hive-render/render.om` (edge renderer for `/hive/board/`, escapes every
   feed string), `om/hive-page/*.om`, `crates/site-builder/src/components/`, `seo::enrich` and the
   Markdown mirror generation. The browser client only parses same-origin `/hive/board/` HTML.
4. `public/js/allen-intro.js` and `scripts/test-allen-intro.cjs`: no X request or `window.twq`
   before consent; refusal persists; `twclid` stored only after consent.
5. `public/install.sh`: stated as byte-identical to the signed copy in aien-dev/sovereign-intelligence
   release `alpha-20261026.2` (sha256
   `b3ba6a3938f418a575c605f8314f62f1aff58de2278509fa23b7266fbb82c93b`); it verifies an Ed25519
   signature and SHA-256 before unpacking. Users run it with `curl ... | sh`.
6. Committed binaries: `om/hive-page/omc`, `om/hive-page/irwasm`, `om/hive-render/hive-render`
   (static AArch64 ELF) and `public/wasm/hive-fresh.wasm`, each with a `.sha256` sidecar;
   `om/hive-page/irwasm.provenance`.
7. Edge templates: `scripts/hive/nginx-location.conf`, `hive-feed.service`,
   `hive-publish.service`, `scripts/hive/DEPLOY-board.md`.
8. `.github/workflows/generated-hive.yml`: pull request and main push on listed paths,
   `contents: read`, runs only skeleton-hash and generated-script-hash tests.
9. Third-party script: `public/vendor/d3-7.9.0.min.js`.

## Trust boundaries

- Untrusted: site visitors; Hive feed content from agents; the `data/now` branch contents until
  `ledger-check` passes; landing URL parameters (`twclid`).
- Trusted: repository source; the committed `omc` (sha256 recorded); GitHub Pages; the edge host
  operator; the release named by `public/install.sh`.
- Third parties reached by visitors: X (`static.ads-twitter.com` and analytics hosts) only after
  consent.

## Threat model summary

- Assets: visitor browsers (XSS), privacy of the private ledger and account data, integrity of the
  installer served to users, deploy credentials.
- Attackers considered: hostile text in feed or ledger rows; a pull request that alters generated
  artifacts; a push to `data/now`; a tampered binary under `om/`.
- Defended: escaping in the Omega renderer and builder; ledger check before build and again
  before copy; verifier that rejects outside script sources on every HTML page; consent gate for
  X; digest sidecars for generated artifacts; deploy permissions isolated to one job.
- Not defended / explicitly out of scope: no CSP is installed by this repository; the edge host
  configuration is outside the repository; the Rust process glue in the edge receiver is
  unfinished migration to Omega (AGENTS.md).

## Build from source at a pin

A stable Rust toolchain (`rustup toolchain install stable`); no `rust-toolchain.toml` and no
tracked `Cargo.lock`, so dependency versions are resolved at build time. Omega pages need the
committed `om/hive-page/omc` (sha256
`734f0a39319fbfa930bcc62cb30dbf06d47d78e126372b74f5baf478e6126b61`) on arm64; `irwasm` sha256
`2d235a70c39ac1461a09c41e10e058d962b767ae83893cdcfc693ef6c47182e6`, built from omega-mv
`a84f1e80020dede868b103605484529a9395ad69` `seed/wasm/irwasm.om`; `hive-render` sha256
`c91602525bceb76c858d3b909b698320e47f921aaf83dd11f396fa356536cfc1`.

```sh
cargo build --release --manifest-path crates/site-builder/Cargo.toml
cargo run --release --manifest-path crates/site-builder/Cargo.toml -- build dist
```

## Run every test

```sh
cargo test --workspace
cargo run --release --manifest-path crates/site-builder/Cargo.toml -- build dist
cargo run --release --manifest-path crates/site-builder/Cargo.toml -- verify dist
node scripts/test-allen-intro.cjs dist/js/allen-intro.js
sh om/hive-page/check.sh
sh om/alpha-page/check.sh
sh om/support-page/check.sh
sh om/hive-render/check.sh
```

- `build dist` writes and then verifies the site; the verifier fails on outside script sources,
  plural first-person words, non-canonical names, missing contact lines and unregistered pages.
- The `om/*/check.sh` scripts need arm64 for the committed `omc`.
- AGENTS.md: the remaining suite runs on the Spark; GitHub runs only the hash tests and the build.
- Browser verification of the consent flow is manual. All of the above: NOT_RUN while writing this
  document.
