What changed, and when

Before 2026-09-23 the project used the Sovereign Reciprocal Commons License (SRCL-1.0). On 2026-09-23 it was replaced by Apache-2.0 WITH LLVM-exception. Any page, PDF, or badge that still cites SRCL-1.0 is stale and should be read as superseded by this page.

What the LLVM exception is

The LLVM exception is a standard add-on to Apache-2.0 used by projects built with LLVM toolchains. In plain terms, it keeps the Apache terms workable when the code is combined with LLVM-compiled components, so the license does not accidentally fight the compiler the project is built with. The controlling text is the LICENSE file in the AIENOS repository.
