What changed, and when

Before 2026-09-23 the project used the Sovereign Reciprocal Commons License (SRCL-1.0). It was replaced by Apache-2.0 WITH LLVM-exception on 2026-09-23. On 2026-10-04 the repositories moved to AGPL-3.0-or-later. On 2026-10-23 the compiler, language and runtime repositories returned to Apache-2.0 WITH LLVM-exception, while interplane-mv and benchmarks-mv stay plain Apache-2.0. Any page, PDF, or badge that still cites SRCL-1.0 or AGPL for these repositories is stale.

What the LLVM exception means

Apache-2.0 permits use, modification and redistribution with attribution and NOTICE preservation. The LLVM exception waives Sections 4(a), 4(b) and 4(d) for portions embedded in compiled object code, so binaries built with Omega or CUDA++ are not required to carry the compiler's license. It also waives conflicting Apache-2.0 patent or indemnity terms when the compiled form is combined with GPLv2 software. The controlling text is the LICENSE file in each repository, for example the Omega repository.
