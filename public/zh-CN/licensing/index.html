AIEN 第一方编译器、语言与运行时材料采用 Apache 许可证 2.0 版及 LLVM 例外（Apache-2.0 WITH LLVM-exception）。独立协议与基准测试仓库保持纯 Apache-2.0。本页面为官方声明。若任何其他页面、文档或徽章内容与此不同，以本页面为准。

各仓库内的 LICENSE 文件为控制文本。LLVM 例外允许开发者用 Omega 或 CUDA++ 编译专有模型或 GPU 内核，并以自选条款分发生成的目标代码；它也化解 Apache-2.0 与 GPLv2 在专利和赔偿条款上的冲突。编译器源码本身仍受 Apache-2.0 的署名与 NOTICE 条款约束。

变更内容及时间

2026-09-23 之前使用主权互惠公共许可证（SRCL-1.0）。2026-09-23 改為 Apache-2.0 WITH LLVM-exception；2026-10-04 改为 AGPL-3.0-or-later；2026-10-23 编译器、语言与运行时仓库恢复为 Apache-2.0 WITH LLVM-exception，interplane-mv 与 benchmarks-mv 保持纯 Apache-2.0。仍引用 SRCL-1.0 或 AGPL 的旧页面已过时。

LLVM 例外的含义

Apache-2.0 允许在保留署名与 NOTICE 的前提下使用、修改和再分发。LLVM 例外对嵌入编译目标代码的部分豁免第 4(a)、4(b)、4(d) 条，因此用 Omega 或 CUDA++ 构建的二进制无需携带编译器许可证；与 GPLv2 软件结合时，冲突的专利或赔偿条款亦被豁免。具体以各仓库 LICENSE 为准，例如 Omega 仓库。
