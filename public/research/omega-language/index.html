Omega: A Programming Language Built for Verified Programs

Semantic identity, evidence-bearing dependencies, and a foreign-code boundary that never lets unverified work inside.

M. Drake Stapleton · October 2, 2026
design proposal9 pagesNot peer reviewed
Read PDF LaTeX source Cite

Abstract

Omega is a programming language design built for verified programs. Code is identified by what it means, not by its text: a semantic identity binds the elaborated, normalized semantic object, so identical meanings resolve to identical identities regardless of surface syntax.

Every dependency carries evidence. The check, build, verify, and seal lifecycle keeps unsealed development work in the workspace while only receipt-bound artifacts cross into the resident execution path. Foreign code is data until a disposable, capability-empty native worker verifies it; foreign code qualified through isolation remains isolated in production.

Design proposal; not an implemented language.
